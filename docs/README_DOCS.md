## Objetivos del Proyecto
1.  **Recomendación Inteligente:** Proponer cultivos basados en datos reales de suelo y clima.
2.  **Simulación Futurista:** Permitir a los usuarios proyectar escenarios mediante el simulador "¿Qué pasaría si...?".
3.  **Arquitectura Escalable:** Mantener una base técnica sólida y modular.
