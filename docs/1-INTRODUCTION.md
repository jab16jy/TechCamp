# Introducción

## Qué es AgroCaribe IA

Plataforma avanzada de análisis agrícola que utiliza inteligencia artificial y datos satelitales para optimizar la toma de decisiones en el Caribe colombiano. Procesa variables climáticas y características del suelo para ofrecer recomendaciones precisas sobre los cultivos más aptos para cada parcela.

## Stack Tecnológico

| Tecnología | Propósito |
|------------|-----------|
| React 19 | Biblioteca principal de UI |
| Vite 8 | Bundler y servidor de desarrollo |
| Tailwind CSS 3 | Framework de estilos utility-first |
| Zustand 5 | Gestión de estado global ligera |
| React Router 6 | Navegación y rutas dinámicas |
| Leaflet | Mapas interactivos y datos geoespaciales |
| Axios | Cliente HTTP para APIs |
| Manrope | Tipografía única del sistema |

## Perfiles de Usuario

### Productor
Flujo simplificado: selecciona ubicación, recibe recomendación de cultivo con score de afinidad, métricas climáticas y datos satelitales básicos.

### Investigador
Acceso completo: dashboard central, análisis avanzado de suelos, IA predictiva con simulación, monitoreo IoT, reportes técnicos y AgroAsesor con chatbot.

## Objetivos del Proyecto

1. **Recomendación Inteligente:** Proponer cultivos basados en datos reales de suelo y clima
2. **Simulación Futurista:** Proyectar escenarios mediante el simulador "¿Qué pasaría si...?"
3. **Arquitectura Escalable:** Base técnica sólida y modular para crecimiento futuro

## Fuentes de Datos

- **NASA POWER:** Variables climáticas (temperatura, precipitación, humedad, radiación solar)
- **Sentinel-2:** Índices satelitales NDVI y NDWI para salud vegetal
- **QGIS:** Procesamiento SIG y validación de capas geoespaciales

## Estado del Proyecto

Prototipo funcional (MVP) con datos mock. La integración con modelos entrenados con datos reales está planificada para la Fase 2.
