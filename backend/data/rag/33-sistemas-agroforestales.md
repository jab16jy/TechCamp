# Sistemas Agroforestales para el Caribe Colombiano

## Que es un sistema agroforestal (SAF)

Combinacion de arboles con cultivos y/o animales en la misma unidad de
terreno, en forma simultanea o secuencial. Aprovecha las interacciones
positivas entre los componentes.

## SAF recomendados por zona agroecologica

### SAF para zona de bosque seco tropical (bs-T)
Ubicacion: Atlantico, La Guajira, norte Magdalena, norte Cesar, Sucre norte
Precipitacion: 800-1500 mm, temporada seca 5-7 meses

**Arboles recomendados:**
- Algarrobo (Prosopis juliflora) — leguminosa fijadora de N, tolera sequia
- Guacimo (Guazuma ulmifolia) — forrajero, madera, sombra ligera
- Ceiba tolua (Pachira quinata) — maderable, sombra media
- Trupillo (Prosopis juliflora) — forraje en vainas para ganado
- Orejero (Enterolobium cyclocarpum) — leguminosa, maderable

**Cultivos bajo dosel:**
- Yuca, sorgo, frijol caupi, patilla, melon (en callejones entre arboles)

**Diseno:**
- Arboles en franjas cada 12-20m, orientados Este-Oeste
- Cultivos en callejones de 10-18m entre franjas de arboles
- Los arboles se podan al inicio de lluvias para permitir luz a los
  cultivos anuales

### SAF para zona de bosque humedo tropical (bh-T)
Ubicacion: Sur Cordoba, sur Bolivar, Uraba, Magdalena medio
Precipitacion: 2000-3500 mm, sin temporada seca marcada

**Arboles recomendados:**
- Cacao (Theobroma cacao) — cultivo principal con sombra
- Platano — sombra temporal para cacao joven
- Maderables: Abarco (Cariniana pyriformis), Roble (Tabebuia rosea), Nogal
  cafetero (Cordia alliodora)
- Frutales: Zapote, Aguacate, Mango

**Diseno:**
- Cacao a 3x3m, arboles maderables a 12x12m
- Platano como sombra temporal removible al ano 3-4
- Estrato medio: cacao (4-6m)
- Estrato alto: maderables (20-30m)

### SAF silvopastoril (arboles + pastos + ganado)

**Arboles para sistemas silvopastoriles:**
- Leucaena (Leucaena leucocephala) — banco de proteina, fija N
- Matarraton (Gliricidia sepium) — forrajero, cercas vivas, fija N
- Saman (Samanea saman) — sombra, leguminosa, forraje en vainas
- Guacimo (Guazuma ulmifolia) — fruto comestible para ganado
- Orejero (Enterolobium cyclocarpum) — sombra, leguminosa, madera

**Diseno:**
- Arboles dispersos: 25-50 arboles/ha para sombra (NO plantar en bosquetes,
  distribuirlos uniformemente)
- Cercas vivas: Matarraton o Leucaena cada 1-2m en los linderos
- Bancos de proteina: Leucaena o Matarraton en bloques densos (40x40cm)

### SAF de huerto familiar (traspatio)

Multi-estrato para seguridad alimentaria familiar:

- Estrato alto (12-20m): Mango, Aguacate, Coco, Arboles maderables nativos
- Estrato medio (4-8m): Citricos, Guayaba, Papaya, Platano, Cacao
- Estrato bajo (1-3m): Cafe (si altitud >800m), Achiote, Cana
- Estrato suelo (0-0.5m): Yuca, Name, Frijol, Hortalizas, Aromaticas
- Animales integrados: Gallinas (control de insectos), Cerdos (aprovechan
  fruta caida), Abejas (polinizacion y miel)

## Beneficios comprobados de los SAF

| Indicador | Monocultivo | SAF multi-estrato |
|-----------|------------|-------------------|
| Biodiversidad | Muy baja | 10-50x mas especies |
| Temperatura bajo dosel | Igual a ambiente | 2-5 C menos |
| Humedad del suelo | Variable | 20-40% mas estable |
| Materia organica | 1-3% | 4-8% |
| Riesgo economico | Alto (depende de 1 precio) | Bajo (productos diversificados) |
| Captura de carbono | Baja | 5-15 t CO2/ha/ano |
| Necesidad de fertilizantes | Alta | Media-baja (los arboles reciclan nutrientes) |
| Resiliencia a sequias | Baja | Alta (microclima, raices profundas) |
