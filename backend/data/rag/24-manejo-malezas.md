# Manejo de Malezas en Cultivos Tropicales

## Principio fundamental

El periodo critico de competencia (PCC) de malezas define el tiempo que el
cultivo DEBE permanecer libre de malezas para no perder rendimiento. Fuera
de este periodo, las malezas no afectan significativamente la produccion.

## Periodo critico por cultivo en el Caribe

| Cultivo | PCC (dias despues de siembra) | Rendimiento perdido si NO se controla |
|---------|------------------------------|--------------------------------------|
| Maiz | 15-45 dds | 30-70% |
| Yuca | 30-90 dds | 50-80% |
| Arroz | 15-45 dds | 40-80% |
| Frijol | 10-35 dds | 40-70% |
| Name | 30-120 dds | 60-80% |
| Algodon | 15-60 dds | 50-75% |
| Sorgo | 15-40 dds | 35-60% |
| Platano | 30-90 dds | 30-50% |
| Cacao | 0-12 meses (establecimiento) | 50-70% |

## Malezas principales del Caribe colombiano

### Gramineas (Poaceas)

| Maleza | Cultivos afectados | Control recomendado |
|--------|-------------------|---------------------|
| Caminadora (Rottboellia cochinchinensis) | Maiz, arroz, sorgo | Pendimetalina 3 L/ha pre-emergente |
| Liendre puerco (Echinochloa colona) | Arroz, maiz | Propanil 5-7 L/ha, Butaclor 3 L/ha |
| Paja mona (Leptochloa spp.) | Arroz, pastos | Cyhalofop-butil 0.8 L/ha |
| Guarda rocio (Digitaria sanguinalis) | Multiple | Pendimetalina, Glifosato en pre-siembra |
| Pasto Johnson (Sorghum halepense) | Maiz, sorgo, algodon | Nicosulfuron 1 L/ha en maiz |

### Hojas anchas (Dicotiledoneas)

| Maleza | Cultivos afectados | Control |
|--------|-------------------|---------|
| Bledo (Amaranthus spp.) | Multiple | Atrazina 2-3 kg/ha, 2,4-D 1 L/ha |
| Batatilla (Ipomoea spp.) | Maiz, yuca, platano | 2,4-D + Picloram, cobertura del suelo |
| Escoba (Sida spp.) | Multiple | Metsulfuron 15-20 g/ha |
| Dormidera (Mimosa pudica) | Pastos, yuca, platano | Triclopyr 2 L/ha |
| Botoncillo (Eclipta alba) | Arroz, maiz | Propanil, Bentazon 2 L/ha |

### Ciperaceas (Coquitos)

| Maleza | Cultivos | Control |
|--------|----------|---------|
| Coquito (Cyperus rotundus) — PEOR maleza del mundo | Todos | Halosulfuron 50 g/ha, rotacion con cobertura densa |
| Cortadera (Cyperus esculentus) | Arroz, maiz, algodon | Bentazon 2 L/ha |
| Estrella (Cyperus difformis) | Arroz | Bentazon o Bispiribac sodico |

## Metodos de control

### Control Cultural (PREVENTIVO — la mejor estrategia)
- Cobertura del suelo con residuos de cosecha (5-10 cm de mulch = 80%
  menos malezas)
- Distancias de siembra que cierren rapido el dosel
- Cultivos de cobertura: Kudzu, Canavalia, Mungo, Mucuna
- Semilla certificada (libre de semillas de malezas)
- Rotacion de cultivos (rompe el ciclo de malezas especializadas)

### Control Mecanico
- Deshierba manual: efectiva pero costosa ($200,000-400,000/ha en jornales)
- Cultivadora de traccion animal: 1-2 pases entre surcos
- Motoazada o motocultor: ideal en agricultura familiar
- Control mecanico: hacer en epoca seca para que las malezas arrancadas
  mueran rapidamente

### Control Quimico — Herbicidas por cultivo

| Cultivo | Pre-emergente | Post-emergente |
|---------|--------------|----------------|
| Maiz | Atrazina 2-3 kg/ha, Pendimetalina 3 L/ha | Nicosulfuron 1 L/ha, 2,4-D 1 L/ha |
| Arroz | Butaclor 3-4 L/ha, Oxadiazon 2 L/ha | Propanil 5-7 L/ha, Bispiribac 0.4 L/ha |
| Yuca | Diuron 2 kg/ha (pre-emergencia) | Glifosato dirigido (proteger tallo de yuca) |
| Frijol | Pendimetalina 3 L/ha | Bentazon 2 L/ha, Fluazifop 1 L/ha |
| Algodon | Pendimetalina 3 L/ha, Diuron 1.5 kg/ha | Glifosato dirigido, MSMA |
| Sorgo | Atrazina 2 kg/ha, Pendimetalina | Atrazina post-temprano, 2,4-D |

### Manejo Integrado de Malezas (MIM)

1. **Antes de sembrar**: Falsa siembra (regar→germinar malezas→eliminar)
2. **Siembra**: Usar semilla limpia, distancias optimas
3. **Pre-emergencia**: Aplicar herbicida residual inmediatamente despues de sembrar
4. **Post-emergencia temprana**: Eliminar malezas en el PCC
5. **Post-cosecha**: NO dejar el suelo desnudo. Sembrar cobertura o mantener residuos

Estrategia combinada de herbicidas con diferentes modos de accion para
evitar resistencia (ej: Atrazina [fotosistema II] + Pendimetalina
[division celular] + Nicosulfuron [ALS]).
