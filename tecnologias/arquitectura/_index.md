# 🏗️ Arquitectura de Software

Patrones y estilos arquitectónicos para organizar el código y escalar aplicaciones.

## Notas

### 🏗️ Estilos Arquitectónicos
- [[Clean Architecture]] — Regla de dependencia y capas concéntricas
- [[MVC]] — Modelo-Vista-Controlador
- [[Por Capas]] — Separación en capas (presentación, negocio, datos)
- [[Feature Based]] — Organización por funcionalidades

### 📡 Comunicación
- [[Event-Driven Architecture]] — Comunicación asíncrona mediante eventos
- [[Event Sourcing]] — Almacenamiento de cambios como eventos inmutables
- [[Message Broker]] — Middleware de mensajería asíncrona
- [[Service Discovery]] — Localización automática de servicios
- [[RabbitMQ]] — Message broker AMQP
- [[Apache Kafka]] — Plataforma de event streaming distribuida

### 🔧 Transversales
- [[ORM]] — Mapeo Objeto-Relacional
